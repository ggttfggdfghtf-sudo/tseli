Цели — приложение для iPhone и Android

1. Загрузите все файлы из этой папки (кроме README.txt) в хранилище на GitHub.
2. В хранилище: Settings → Pages → Branch: main, / (root) → Save.
3. Через 1–2 минуты откройте https://ВАШ-ЛОГИН.github.io/tseli/ в Safari
   и нажмите «Поделиться» → «На экран „Домой“».
